# 🌦️ Weather App

A responsive and user-friendly weather application built with **HTML, CSS, and JavaScript** using the **Open-Meteo API**.

The app allows users to search for a city and view its current weather information in a simple and clean interface.

## 🌐 Live Demo

👉 https://jivesh07.github.io/weather-app/

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature
- 🌤️ Show current weather condition
- 💧 Display humidity
- 💨 Display wind speed
- 🌡️ Show feels-like temperature
- 🌦️ Weather icons based on weather conditions
- ⏳ Loading state while fetching data
- ⚠️ Error handling for invalid cities or API errors
- 📱 Fully responsive design
- ⌨️ Search using the Enter key
- 🔑 No API key required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API
- Geocoding API

## 🔌 API

This project uses the **Open-Meteo API** to retrieve weather information.

It also uses the Open-Meteo Geocoding API to convert city names into geographic coordinates.
