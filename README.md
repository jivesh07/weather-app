# 🌦️ Weather App

A responsive weather application built with HTML, CSS and JavaScript using the Open-Meteo API.

## 🚀 Features

- Search weather by city
- Current temperature
- Weather condition
- Humidity
- Wind speed
- Feels-like temperature
- Weather icons
- Loading state
- Error handling
- Responsive design
- Enter key search
- No API key required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API

## ▶️ How to Run

1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Enter a city name.
4. Click Search.

## 🌐 API

This project uses Open-Meteo weather and geocoding APIs.

## 📱 Responsive Design

Works on desktop, laptop, tablet and mobile devices.
