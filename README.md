# 🌦️ Weather App

A responsive and user-friendly weather application built with **HTML, CSS, and JavaScript** using the **Open-Meteo API**.

## 🌐 Live Demo

👉 https://jivesh07.github.io/weather-app/

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Current temperature
- 🌤️ Weather condition and icons
- 💧 Humidity
- 💨 Wind speed
- 🌡️ Feels-like temperature
- ⏳ Loading state
- ⚠️ Error handling
- 📱 Responsive design
- ⌨️ Enter-key search
- 🔑 No API key required

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo Weather API
- Open-Meteo Geocoding API

## ▶️ Run Locally

```bash
git clone https://github.com/jivesh07/weather-app.git
cd weather-app
```

Open `index.html` in your browser, or use VS Code Live Server.
